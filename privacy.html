Privacy Policy

Last updated: November 18, 2026

Clipping is a private, single-user tool. It runs only on its owner's own computer and is used only by its owner to publish short clips to the owner's own YouTube channel. It has no other users and no public sign-up.

Use of YouTube API Services

Clipping uses YouTube API Services. By using Clipping you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

What data Clipping accesses

Clipping requests only the youtube.upload permission. It uses it to upload a video, with a title and description, to the owner's own channel, and only after the owner manually approves each video. It does not read, collect, or store any other YouTube or Google account data, and it does not access any other person's data.

How data is stored

The OAuth access token is stored only on the owner's computer, in a local file. Clipping has no server and no database. Nothing is sent anywhere except to YouTube itself when a video is uploaded.

Sharing

Clipping does not share, sell, or transfer any data to third parties, and does not use cookies or tracking.

Revoking access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.

Data retention and deletion

Clipping keeps no YouTube or Google account data. The only thing it stores is the OAuth token, in a local file on the owner's computer, kept until access is revoked. Revoking access at the Google page above, or deleting the token file, removes it. Videos uploaded with Clipping are managed, and can be deleted, in YouTube Studio like any other video. Requests to delete data can also be sent to the contact address below; they are handled within 7 days.

Changes
